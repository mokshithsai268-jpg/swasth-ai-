# 🧠 SwasthAI Ultra – AI Healthcare Intelligence System

## 📌 Project Overview

SwasthAI Ultra is an AI-powered healthcare web application developed using Python, Streamlit, Machine Learning, and Ayurveda-based health recommendations. The system helps users perform disease risk analysis, receive personalized diet and exercise plans, interact with an AI medical chatbot, find hospitals, and book doctor appointments.

This project was developed as a Mini Project for academic purposes and demonstrates the integration of Artificial Intelligence, Machine Learning, Healthcare Analytics, and Web Technologies.

## 🎯 Objectives

* Predict disease risks using Machine Learning.
* Provide personalized nutrition and diet plans.
* Generate Ayurveda-based health recommendations.
* Suggest exercises and fitness routines.
* Offer AI-powered healthcare assistance through a chatbot.
* Recommend hospitals and specialists.
* Facilitate appointment booking.
